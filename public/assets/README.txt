TFT_18_HELPER local assets

- data/ contains immutable source JSON plus the generated assets manifest.
- units/champions/         : shop champion icon images
- units/championsplashes/  : shop champion splash images
- items/                   : item icons
- traits/                  : trait icons
- augments/                : augment base icons
- home/                    : Set 18 home-page theme art
- info/<topic>/             : reserved manual image slots for the reference page

The original TFT JSON files are not modified.
